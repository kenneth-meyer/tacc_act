# TACC environments

Your one-stop shop for creating coding environments on TACC systems! The start of this repo will focus on `python` environments, but will be expanded as needed.

Feel free to contribute your install workflow / setup to this repo via a pull request. While debugging installation errors is encouraged and is a good skill to have, I hope that this repo provides easier access to software for researchers who use TACC systems (and other HPC systems).

This would have been more helpful pre-AI, but ... better late than never.

## uv
uv is used as a package manager. I was a pip enthusiast, but uv is "10-100x faster than pip".

## Organization
This repo is in its early stages, and comments on how to best organize it are appreciated. Approaches may be to:
- oragnize by project
- modularize packages so users can select exactly what packages they want
- organzie by area of work (machine learning, finite element-based research, etc)

Half of the purpose of this repo is to remember what packages exist and to integrate them with my lab's codebases.
